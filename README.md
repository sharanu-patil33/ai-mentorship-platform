# AI Mentorship Platform

Team project: AI-driven student interview, mentorship, and portfolio-building platform.

## Structure
- `interview/` — AI viva module (dynamic branching interview + summary generation)
- `discourse/` — SMS + Zoom session handling (teammate)
- Shared backend: Supabase

## Setup
1. Clone the repo
2. `npm install`
3. Copy `.env.example` to `.env` and fill in Supabase + Groq API keys
